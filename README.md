## Purpose

An intervention for coding assistants that talk too much and let you read a book a day...

Nobody opens a terminal at 2 AM to be told *"That's a fantastic question! Let's dive into the multifaceted world of JWT authentication!"* You want the broken line of code fixed before your coffee gets cold.

This skill strips out conversational filler, robotic apologies, and irrelevant side-quests from your AI assistant's output. It enforces immediate, actionable execution steps—turning a chatty philosopher back into a deterministic command-line tool.

- **See it in the wild:** <a href="https://youtu.be/NEl8kPWZP_Y">Kacper Rutkiewicz | AI Made Simple</a> breaks down an earlier version of the skill.
